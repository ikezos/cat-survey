# のら猫 頭数調査

のら猫の頭数を、研究会の人がスマホで記録するための画面です(GitHub Pages で公開)。

- このリポジトリにあるのは画面のコードだけです。調査の記録・写真・入力した人の情報は入りません。
- 記録はまず端末の中(IndexedDB)に保存し、登録された入力者が Google でログインすると、受け付け(Google Apps Script)へ送ります。
- プライバシーポリシー: https://cats.ikezos.com/privacy.html
- 「見本のデータ」の20頭は架空のものです(名古屋市内の区域の見本)。
- 地図は Leaflet 1.9.4(lib/LEAFLET-LICENSE.txt)と OpenStreetMap の地図を使っています。
- カードの QR の読み取りは jsQR(Apache-2.0、lib/JSQR-LICENSE.txt)を使い、端末の中だけで行います。
- 猫は消さずに「いなくなった」と記録できます(いなくなった日と理由)。理由の選び肢は、受け付けのシート「選び肢」の「いなくなった理由」で変えられます。
- 一覧を開いた時は「すべて」(未送信も送信済みも)が出ます。
- 送れない時は、端末に残して1分ごとに自動で送り直します。
- 管理者は、本番の前に「試しの記録をすべて消す」が使えます(2回の確かめつき)。
- 使い方: https://cats.ikezos.com/help.html

## 一緒に開発してくださる方へ

獣医師やボランティアの方、地域の猫の調査に関心のある開発者の方からのご連絡を歓迎します。support@ikezos.com までご連絡ください。GitHub の Issues からでもかまいません。

## 自分の地域で使うには

- 画面(このリポジトリ)は誰でも使えます。
- 記録を集める受け付け(Google Apps Script)は、それぞれご自分の Google アカウントで作ります。
- 記録はこのリポジトリには入りません。
- 詳しい手順は後日書きます。
